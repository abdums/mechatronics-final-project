# Smart Automatic Gate

An Arduino Uno project that uses an HC-SR04 ultrasonic distance sensor to control an SG90 servo.

**Website:** https://abdums.github.io/mechatronics-final-project/

## Files

- `index.html` — project website
- `assets/` — photos, block diagram, and integration demonstration
- `firmware/smart_gate.ino` — Arduino control sketch

## Progress — November 23, 2026

The servo and ultrasonic sensor have been tested individually and together. Next, I will assemble and attach the lightweight barrier arm and check repeated opening and closing.
